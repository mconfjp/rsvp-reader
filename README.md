# RSVPリーダー

日本語の文章を文節ごとに画面中央へ高速表示して読む、RSVP（Rapid Serial Visual Presentation）速読リーダー。
スマホのブラウザ向け。ホーム画面に追加するとアプリとして使え、オフラインでも動く。

## 使い方

1. 読みたい文章を貼り付けて「読む」
2. 画面タップ（PCではスペースキー）で再生／一時停止
3. 一時停止中は前後の文が表示され、読んでいた箇所がハイライトされる

| 操作 | スマホ | PC |
|---|---|---|
| 再生／一時停止 | 画面タップ・▶ボタン | Space / Enter |
| 前の文の頭へ／次の文へ | ⏮ ⏭ ボタン | ← / → |
| 速さ | − / ＋ ボタン | ↑ / ↓ |
| 一覧に戻る | ← 一覧 | Esc |

## 記事をワンタップで読む

[howto.html](https://mconfjp.github.io/rsvp-reader/howto.html) に手順がある。

- **iPhone**：ショートカット「RSVPで読む」（[iCloudリンク](https://www.icloud.com/shortcuts/2f5ec157e4cc4ce2a1e8d28ff109fd19)）。Safariの共有メニューから、リーダー機能で取り出した本文をクリップボードにコピーして `#clip` を開く。アプリ側の「クリップボードから読む」ボタンで受け取る（iOSではクリップボードの読み取りにタップが必要なため）
- **PC**：ブックマークレット。選択範囲、`article`/`main` 内の本文要素、ページ全体の順に文章を探す

アプリは `#text=<URLエンコードした本文>&title=<タイトル>` で文章を受け取る（`title` は省略可）。`#` 以降はサーバーに送られない。

## 仕様

- **区切り**：`Intl.Segmenter` で単語に分割し、助詞・助動詞・送り仮名・句読点を前の語に、開き括弧を次の語にくっつけて文節に近い単位にする（`chunker.js`）。連続する漢字・カタカナは複合語としてまとめる
- **表示時間**：どの文節も同じ時間。速さは 100〜1000 文節/分（25刻み、初期値 300）。再生を始めた直後の5文節は 2.0→1.2 倍でゆっくり表示する
- **長い文節**：分けずにそのまま表示し、画面幅に収まるよう文字を縮小する
- **表示**：画面中央揃え。文字サイズは小・中・大、テーマは自動・ライト・ダーク
- **履歴**：最大30件を端末（localStorage）に保存。最後に開いたのが一番古いものから削除する。タイトルは冒頭20文字から自動で付け、後から変更できる。読んでいた位置は文字オフセットで保存する
- **その他**：再生中は Wake Lock で画面が消えないようにする。バックグラウンドに移ると一時停止する

貼り付けた文章は端末のブラウザ内にだけ保存され、外部には送信されない。

## 開発

ビルド不要。`python3 -m http.server` などで配信して開く。
